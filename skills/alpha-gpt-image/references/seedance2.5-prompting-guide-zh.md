# Seedance 2.5 提示词工程手册

## 1. 先理解它在做什么

Seedance 2.5 不是把关键词逐条执行成动画，而是把文字、图片、视频、音频共同解释成一段带有场景、人物、时间、镜头、动作、声音和风格的视听结果。公开资料把它描述为统一的多模态音视频联合生成架构；具体内部网络和权重优先级没有公开，因此下面的“优先级”是可验证能力加生成经验的工程化表达，不是官方披露的内部算法。

可以把一次生成理解成四层约束：

1. **参考素材层**：人物长相、服装、场景、声音、动作参考、白模/分镜和关键帧。
2. **空间层**：谁在画面哪一侧、前中后景、朝向、距离、移动路径、光从哪里来。
3. **时间层**：每个阶段发生什么，动作的先后、因果和结果。
4. **表现层**：镜头、焦点、光影、材质、色彩、声音和艺术风格。

模型最容易执行的是“可见、可定位、可分段”的描述；最容易丢失的是抽象形容词、相互冲突的要求、没有时间跨度的复杂动作，以及没有空间锚点的多人互动。

## 2. 最稳的提示词结构

建议按下面顺序写，复杂片段只使用需要的部分：

```text
参考素材映射
一句话总纲：主体 + 地点 + 事件 + 风格 + 核心运镜
场景与空间站位
首帧状态
时间轴/镜头段落
动作因果与物理效果
镜头与焦点
光影、材质、色彩
对白、环境声、音效、音乐
贯穿全片的锁定项
```

### 参考素材映射

不要只给素材编号，也不要只在图片上写名字。要明确“哪个素材负责什么”：

```text
Image 1 是女主角的身份与服装参考；Image 2 是仓库场景参考；
Video 1 只参考剑术动作和镜头轨迹；Audio 1 只参考男主的声音音色。
```

如果素材已经准确，直接说“严格参考 Video 1 的动作和运镜”即可，不要把同一动作再用另一套文字重复描述，以免产生冲突。

### 一句话总纲

```text
写实电影风格，雨夜港口，女侦探追踪一名携带红色手提箱的男人，
一镜到底，手持稳定器从侧后方跟拍并在结尾拉成全景。
```

### 时间轴

Seedance 2.5 支持时间戳。用连续区间，通常以 1 秒为基本单位；不要留下时间空洞，也不要用时间戳控制“每秒抖头三次”这类高频动作。

```text
0-3s：建立全景和人物关系。
3-7s：主动作发生，明确开始位置、方向和目标。
7-11s：碰撞/反应/状态变化。
11-15s：结果、情绪收束或新的叙事钩子。
```

同一段时间里内容过多，模型会增加切镜、跳过动作或自行改剧情；内容过少，模型会自由发挥。

## 3. 把“想要的感觉”改成可执行画面

### 抽象词的改写方法

| 不够可执行 | 更可执行 |
|---|---|
| 高速、很震撼 | 低机位中远景；主体从画面左侧高速冲向右侧；背景产生明显运动拖影；相机沿同一方向跟拍，冲过镜头后才快速拉焦到远处目标 |
| 激烈打斗 | A 先出拳，B 向后撤半步并抬臂格挡；拳头接触前停留一瞬，接触后 B 的肩膀和衣服受力向后，脚底滑过尘土，随后恢复防守姿态 |
| 很悲伤 | 角色低头，呼吸变浅，肩膀轻微颤抖，拇指反复摩擦戒指，眼睛看向地面而不是镜头 |
| 仙气飘飘 | 山谷薄雾贴近地面，冷白月光从右后方勾勒轮廓，衣袖随上升气流向左后方飘动，远处粒子缓慢上升并逐渐消散 |
| 强大魔法 | 右手掌心先聚集少量青色粒子，粒子绕掌心旋转并压缩成球体；角色向前推掌，能量沿右上方直线飞行，撞上护盾后产生环形冲击波，照亮地面并留下短暂烟尘 |

核心公式是：**主体 + 起始状态 + 动词 + 方向/速度/幅度 + 目标 + 接触结果 + 后续状态**。

## 4. 高速运动与复杂动作

### 写高速运动的五个锚点

1. **起点**：人物或物体在首帧的具体位置。
2. **路径**：直线、弧线、绕柱、跃过障碍物，写清左右和前后关系。
3. **相机关系**：相机跟随、迎面、侧追、俯拍还是固定机位。
4. **速度证据**：运动拖影、衣摆滞后、脚步扬尘、镜头反应，而不是只写“快”。
5. **结束状态**：停在哪里、身体如何刹车、惯性如何释放。

示例：

```text
0-2s：低机位侧面中景，黑衣剑客已在画面左侧三米处，身体朝右，右脚前置。
2-5s：他沿港口木板路向右高速冲刺，镜头以相同速度平行跟拍；衣摆和长发略晚于身体甩向后方，脚下木板被踩出细小水花。
5-7s：他在红色灯笼旁急停并转身，前脚压住地面，身体因惯性向前倾后回正，镜头绕到他的正面并锁定眼睛。
```

不要在 2 秒内同时塞入奔跑、三次翻滚、拔剑、跳墙和说长台词。把动作拆成可观察的状态，或用动作参考视频/白模来承载轨迹。

## 5. 激烈打斗与动作逻辑

打斗不是“两个角色互相乱打”，而是可追踪的受力链。每个节拍最好只有一个主要攻击或防御事件：

```text
0-3s：中远景建立双方距离。A 在画面左侧，B 在右侧，相距约四米，二人都面向对方。
3-5s：A 先向前踏步，右拳从胸前直线击向 B 的左肩；B 向自己的右侧闪避，拳头擦过衣服，没有穿透身体。
5-7s：B 借闪避的转身惯性扫腿；A 后撤并用前臂下压格挡，鞋底在湿地面滑动半米，水花沿受力方向飞散。
7-10s：A 抓住 B 的手腕，利用拉力把 B 带向画面左侧；B 顺势翻身脱离，不凭空瞬移，落地后保持低姿态。
10-12s：两人重新拉开距离，保持左 A、右 B 的屏幕方向，短暂对视后准备下一回合。
```

关键写法：谁先动、身体哪一部分接触、接触点、受力方向、脚步和重心、衣物/尘土/碎片的滞后、动作结束后双方在哪里。需要血腥或受伤时也要写成可见结果；如果不需要血腥，明确“非血腥、无肢体断裂”。

## 6. 剧情连贯性与一镜到底

先在首帧建立地理关系，首帧就把之后必须认识的主体放进画面。每个时间段都回答三件事：**发生了什么、为什么发生、发生后状态怎样**。

```text
一镜到底，无切镜。相机从门口进入客厅，始终从人物背后右侧观察。
0-5s：母亲在左前景收拾桌面，男孩在右后景靠窗寻找足球；两人都在画面内。
5-9s：男孩发现足球滚到沙发下，蹲下伸手；母亲听到声音后停下动作并转头看向右后方。
9-14s：男孩把球拉出，球撞到桌脚，桌上的玻璃杯轻微震动；母亲走近扶住杯子。
14-18s：男孩抬头与母亲对视，母亲的表情从责备变成无奈，镜头后退露出完整客厅。
```

跨镜头或延长视频时，重复锁定人物身份、服装、道具、伤口、屏幕方向、光线方向和声音状态。延长片段要说明“第一帧紧接上一段最后一帧”。

## 7. 多人场景、空间站位与人物锁定

多人场景最重要的不是人物名字，而是“素材映射 + 画面坐标 + 深度层 + 视线目标 + 发言归属”。

```text
Image 1 是角色 A，Image 2 是角色 B，Image 3 是角色 C。
首帧：A 在画面左前景一米处，面向右；B 在画面右前景两米处，面向左；
C 在两人后方中央三米处，保持安静并看向 A。三人的服装和发型全程不变。
0-4s：A 说台词，只有 A 的嘴唇运动；B 保持沉默，眼睛看 A；C 仍在背景观察。
4-8s：B 向画面中央走一步并回答，A 只做轻微点头；C 不加入对话。
8-12s：相机拉远，三人仍保持左 A、右 B、后方 C 的空间关系。
```

屏幕左/右以相机为准，不以角色自身左右为准。5 个以内的主体通常更稳定；人物图像参考 1-8 个较稳，音频/视频主体参考 1-5 个较稳，更多主体不是不能做，但应减少镜头复杂度并准备多次尝试。超过 5 个图像主体时，分开的单视图通常比一张塞入多角度多人图更稳定。

## 8. 动漫、玄幻、仙侠等风格

不要只写“动漫风”或“仙侠风”。将风格拆成：

```text
渲染方式 + 线条/材质 + 光影规则 + 色彩层次 + 服装与场景世界 + 动作语言
```

动漫示例：

```text
2D 手绘动画，清晰但不僵硬的线稿，中等线宽，平涂色块与少量软阴影，
角色轮廓稳定，背景使用分层视差；快速挥剑时允许短暂手绘 smear frame，
但人物脸部和服装细节不变。夕阳从左后方照入，橙色轮廓光与蓝紫色阴影形成对比。
```

仙侠示例：

```text
东方仙侠电影质感，青灰山谷、湿润岩石、深红法衣、冷白月光；
真丝衣袖有重量并受风向影响，法阵发光会照亮附近岩壁和人物下颌，
雾气贴地流动，镜头以缓慢环绕和升降为主，不使用现代城市元素。
```

只选一个主风格，再用少量次要风格补充。诸如“写实、二维、油画、赛博朋克、古典水墨”同时作为主风格，会造成材质和运动规则冲突。

## 9. 技能特效与魔法效果

特效要写“来源、形状、轨迹、速度、与环境的交互、消散方式”：

```text
角色双手之间形成一枚直径约半米的金色符印。符文先由稀疏光点沿圆周顺时针排列，
再逐渐填满中心。角色向前推掌，符印沿画面左下到右上的直线飞出，
拖出短而密的金色粒子尾迹。它击中石墙后产生一次向外扩张的环形冲击波，
墙面出现裂纹和落尘，附近人物衣服被冲击风向后吹。光效在两秒内变暗，
粒子因惯性向前漂移后消散；只发生一次爆炸，不产生随机额外法术。
```

如果有动作视频或白模，明确它只负责什么：

```text
严格参考 Video 1 的施法手势、施法节奏和相机轨迹；
使用 Image 1 的人物身份，使用 Image 2 的法阵材质与色彩。
```

白模/3D clay render 适合承载人物站位、运动路径、镜头和节奏；风格图适合承载材质、光影、色彩和世界观。官方建议白模保持简单、粗粒度。

## 10. 镜头、光影和声音

镜头至少写四项：景别、角度、运动、焦点目标。

```text
低机位中远景，镜头从角色左后方平行跟拍；角色接近门口时推近到中近景，
先对焦手中的钥匙，再在钥匙插入锁孔后拉焦到门后的黑暗。
```

对专业术语不确定时，加上可见结果，例如“rack focus：前景树枝由清晰变模糊，背景人物逐渐清晰”。

光影写光源方向、硬/柔、色温、阴影落点和反射材质：

```text
主光来自画面右后方的冷蓝月光，边缘硬、形成清晰长影；
左侧只有低强度暖色火光补光，火光在金属剑身上产生跳动反射；
不使用正面平光。
```

声音写来源和同步点：脚步对应地面、金属碰撞对应接触、对白指定说话人。需要控制时可使用“无字幕”“无 BGM”“只保留环境声和动作音”；负面控制最适合字幕和音频，画面内容尽量用正向描述。

## 11. 参考素材和任务模式怎么选

- **纯文字 T2V**：适合概念探索；必须自己写空间、动作和风格。
- **R2V 主体参考**：用人物/场景/道具图锁定身份，再用文字写动作和镜头。
- **动作/镜头参考视频**：把复杂轨迹交给视频，文字只说明要保留哪一部分。
- **3D 白模**：适合多人站位、复杂走位、镜头路径和节奏。
- **首帧/尾帧**：适合严格控制开头与结尾；使用真正的 first_frame/last_frame 角色会锁定宽高比。
- **多张关键帧**：适合要求画面接近指定节点；比多格故事板更严格。
- **多格故事板**：适合高层剧情参考；建议 15 格以内、简单线稿，不要期待逐帧还原。
- **编辑/延长**：用时间戳明确“从 A 改成 B”或“从最后一帧继续”，并写出哪些内容必须保持不动。

Seedance 2.5 单次最多生成约 30 秒；公开文档列出的参考上限为 30 张图片、10 段视频、10 段音频，但稳定性通常会随主体和素材数量上升而下降。素材不是越多越好，而是每个素材都要有明确职责。

## 12. 常见失败与修复

| 失败现象 | 常见原因 | 修复 |
|---|---|---|
| 人物脸和服装漂移 | 参考未映射，或每段重新描述不同外观 | 用角色标签和单一身份参考，贯穿写“保持不变” |
| 打斗像随机挥舞 | 没有先后、接触点和受力结果 | 每个节拍只写一个攻击/反应，并固定屏幕方向 |
| 高速动作断裂 | 动作过多、没有路径或结束状态 | 减少动作数，写起点-路径-终点，或使用动作参考视频 |
| 多人互换位置/重复出现 | 只有名字，没有空间坐标和深度层 | 首帧建立左/右/前/后、距离和视线目标 |
| 镜头乱切 | 长时间段塞入太多事件，或写了相互矛盾的运镜 | 分配合理时间，明确“一镜到底/切镜”，每次只做一个主要运镜 |
| 特效漂亮但不合物理 | 只写颜色和“震撼” | 补来源、轨迹、接触、光照环境和消散 |
| 画面有字幕或乱配音乐 | 没有负面音频/字幕控制 | 明确“无字幕”“无 BGM”或列出唯一需要的声音 |

## 13. 推荐的迭代顺序

一次只改一个变量：

1. 先修正人物身份和首帧空间。
2. 再修正动作顺序、路径和受力。
3. 再修正镜头与时间分配。
4. 最后调风格、光影、声音和特效细节。

如果连续几次失败，优先减少事件、减少角色、减少参考素材，而不是继续堆形容词。复杂内容应拆成多个片段，用延长或编辑保持连续性。

## 14. 可直接复制的总模板

```text
【参考素材映射】
Image 1 = 主体 A 的身份、脸部、发型和服装；
Image 2 = 场景与材质；Video 1 = 动作和镜头参考；Audio 1 = 主体 A 的声音。

【总纲】
[时长]，[画幅]，[主风格]。主体 A 在[地点]完成[事件]，
采用[景别/角度/运镜]，整体节奏[缓慢/紧凑/逐渐加速]。

【空间与首帧】
镜头从[相机位置]观察。主体 A 在画面[左/右]、距[地标]约[距离]，
面向[方向]并看向[目标]。主体 B 在[位置]，位于[前/中/后景]。

【时间轴】
0-[x]s：建立[空间/人物关系]，相机[动作]。
[x]-[y]s：主体 A [具体动作]，沿[路径]到达[位置]；
动作导致[可见结果]。
[y]-[z]s：主体 B [反应/反击/对白]，保持[站位/屏幕方向]。
[z]-[结束]s：状态收束为[最终画面]，相机[结尾动作]。

【物理与风格】
身体有[重量/惯性]；衣服、头发、烟尘、液体和粒子受[风向/重力/接触]
影响。主光从[方向]来，色温[冷/暖]，阴影落向[方向]。

【声音与锁定】
只有[对白/环境声/动作音/音乐]；[无字幕/无 BGM]。
全片保持主体身份、服装、道具、伤口、光线方向、屏幕方向和画面风格一致。
```
