## 战斗简报

为每场战斗确定：目的、核心视觉、胜负、时长、人数、角色战斗语言、场景机制、节奏/动作密度、强度曲线和结尾类型。

### 核心卖点门禁

每场短打斗必须先提炼不超过 2 个核心卖点：观众看完最应该记住的体验，例如速度、压迫、命中感、能力对抗、角色表演、空中机动、尺度或终局爆发。卖点不是招式清单，也不是风格形容词，而是需要被画面证明的观众体验。

为每个卖点指定至少一个可观察的证明节拍，并在节拍、路线、摄影、特效和声音设计中标明它服务哪个卖点。若一个动作、镜头或特效不证明卖点、不推进剧情或不完成连续性，它只能作为可选装饰，进入 B 稿前优先删除。两个卖点互相冲突时，必须指定主卖点，另一个降为辅助，不让多个视觉主语平均分配注意力。

角色战斗语言至少包括：

`主战距离 + 速度/力量 + 武器 + 移动方式 + 攻击习惯 + 防御方式 + 能力属性 + 弱点`

差异不能只靠服装或颜色。例如：

- 轻灵剑客：切角、卸力、短促精准、避实击虚。
- 重装战士：压迫推进、硬接、重劈、环境承伤。
- 射手：制高点、封落点、预判、换位、距离管理。
- 控制者：改变地形、限制路线、创造队友窗口。

## 节奏与动作密度

在仪式感/慢节奏、标准电影动作、高速连续攻防、爆发型动漫或神话动作中明确选择。高密度不等于多个独立系统同时乱动；它来自同一攻防目的下连续发生的起手、应对、变招、闪避、追击和反击。

“一镜一个主要视觉因果”解释为“一镜一个主导攻防目的”，不是“一镜一个孤立动作”。高速动作镜头通常允许 2–4 个由上一动作直接触发的微动作，例如：

`突刺 → 架开 → 转腕反削 → 后仰闪避`

详细模式、预算与验收读取 `action-density-and-rhythm.md`。

## 人数结构

### 一对一

关注试探、识别、反制、升级和胜负。双方都要有有效选择，不要单纯轮流放技能或站着等待。高速模式至少安排一次明确攻守互换，并让终结发生在充分交锋、受阻或反转之后。

常用曲线：试探 → 第一次接触 → 战术变化 → 优势转换 → 终局。切磋可用三次不同等级碰撞；写实格斗可围绕距离和重心反复争夺。

### 一对多

主角是视觉主语，敌群按功能和批次出现：封路、扑杀、重击、远程、强化。避免“排队送死”，但也不要让所有敌人同时执行独立复杂动作。

路线采用主角穿群走廊：进入 → 突破区 → 转折区 → 高潮区 → 收束。每一区只展示一个新的能力维度。

### 团队对群体

给每人明确岗位与活动区：主攻、控制、支援、侧翼、远程、终结。协同必须是因果接力：A改变状态 → B利用状态 → C完成结果。角色岗位和每个节拍还应标注服务哪个核心卖点，避免协同动作变成无目的并行表演。

团队角色按五轴正交：空间区、主战距离、动作/武器来源、属性材质行为、战术功能。只换服装或颜色不算区分。协同证据分为同框协同与蒙太奇协同：蒙太奇可以用共享战场、匹配方向、目标状态连续和结果接力完成中段协作；但至少需要一次同框空间确认和一次可读的状态接力高潮，避免多人只是各自技能展示后在结尾站队。

每个镜头只突出一个人，其他人维持支援动作或可读站位。摄影机焦点一次只交接一次。

### 多对多

将战场拆为 2–4 个局部战团，建立主轴与主角。通过救援、夹击、接力、目标物或局部胜负切换焦点。不要同时描述每个人完整招式。

### Boss 战

建立威胁区、回避区、弱点窗口和终结区。Boss 的体型与攻击范围决定路线；主角的成功来自识别和利用窗口，而非连续无代价输出。

## 场景模式

- **决斗/切磋**：实力对等、互相识别、克制升级。
- **伏击**：信息不对称、突然起手、夺回主动权。
- **追杀/追逐**：路径、障碍和速度差是主因果。
- **突围**：目标是到达出口，不是击倒所有人。
- **守护/护送**：围绕被保护对象或区域设计防线。
- **守点**：空间不能随意放弃，利用入口与瓶颈。
- **清场展示**：逐级展示能力，但控制重复动作。
- **生存战**：资源、疲劳、伤势与环境风险逐渐积累。
- **潜行击杀**：信息、遮挡、声音与视线比大爆炸重要。
- **载具/空战/水下**：增加第三维运动，但减少同时发生的细节。

## 动作因果

完整攻击事件：

`准备姿态 → 发力来源 → 运动轨迹 → 接触位置 → 命中反馈 → 对手惯性 → 动作余势`

短镜头可以压缩，但不能省略接触与结果。连续微动作链共享一个主因果时，不要把每一步误判成互不相关的独立事件。力量反馈分为：

1. 人物：皮肤/护甲形变、重心变化、表情、呼吸。
2. 武器：震颤、偏转、卡住、开裂、热量或放电。
3. 环境：裂纹、灰尘、水花、木屑、残骸、回声。
4. 特效：在接触点出现并沿介质传播。

抽象词“激战、连续攻击、猛烈交手”必须改写为具体主体、方向、接触和受力。动作镜头至少说明：攻击者做什么、对手如何应对、该动作如何自然进入下一动作或下一镜。

高速打斗的爽感来自“攻击 → 应对 → 变招 → 追击/反击”的连续因果，不是连续摆姿势、独立技能展示或全程倍速；每个高速动作镜头只保留一个主导攻防目的，允许 2–4 个前后直接触发的微动作。双方都必须拥有主动进攻、有效应对与反击机会；终结前应有受阻、代价或明显优势反转。特效必须依附于身体、武器或明确来源，且服务攻防，不得替代动作本身。高速密度与节奏细节见 [action-density-and-rhythm.md](action-density-and-rhythm.md)。

## 武器战语法

武器不只是挥砍。围绕武器设计持续的距离与攻击面争夺：

- 表现**外线/内线、攻击面、有效距离与近身死角**：长兵器争外线、枪尖有效距离，短兵器抢内线、近身；
- 武器碰撞后必须出现**重心、路线、攻击选择或环境状态**之一的变化——碰撞不是声音事件，是战术转折；
- 格挡后继续滑动、勾压、卸力、夺线、绕柄或借反弹变招；
- 至少一次交换攻守角色；缴械、武器破坏和终结发生在充分交锋之后；
- **持握方式、左右手、数量、长度、结构和损伤必须连续**（数量/左右手/长度跳变是常见失败）；
- 每次武器碰撞都改变双方重心、朝向、路线或下一击选择。

合格示例：`A突刺抢外线 → B用枪杆架开卸力 → A顺势转腕反削 → B后仰避刃退出半步、枪杆借力反弹换内线`。这条链中距离、攻击面与攻守关系每次都在变。

## 多人焦点规则

- 一镜一个主导攻防目的和主要视觉主语；允许同一对抗关系中的连续微动作链，禁止多人同时运行各自复杂招式。
- 支援角色只完成一个可读贡献，例如封路、挡击或补射。
- 阵营用轮廓、颜色、活动区和武器区分，不靠字幕。
- 群体受击要错开时间、角度、速度和姿态，避免整齐同步倒飞。
- 交锋点标清谁从哪里来、向哪里离开；避免越轴后身份混淆。
- 焦点交接必须携带可追踪的因果桥：投射物、敌人受力、地面状态、刀弧/电流/冰层传播或队友创造的窗口；禁止无因切到下一人重新起招。

## 动作预算

估算每个镜头的负担：

- 主体运动系统数；
- 摄影机运动数；
- 独立攻击因果数；
- VFX/环境运动系统数；
- 身份和武器连续性负担。

低风险：一条攻击—应对微动作链 + 一种摄影机运动 + 一种主要反馈。

高风险：多人独立动作系统 + 高速环绕 + 武器变形 + 群体受击 + 大规模特效同时发生。

遇到高风险，依次采取：删互不相关的次要动作 → 固定摄影机 → 减少同时活动主体 → 保留主攻防链并拆镜头 → 生成后剪辑。不要首先删掉格挡、变招、闪避或即时反击，把连续打斗压成孤立动作。

## 剧本转回合

先把文本拆为两层：

- **不可改的剧情事实**：谁要达成什么、谁阻止、必须出现的目标物/救援/背叛/受伤/撤离、胜负和结尾。
- **可设计的战斗空间**：武器、具体招法、路线、交锋次数、能力升级、摄影与特效。

用“回合”组织戏剧推进，而不是把镜头数当作回合数。每一回合至少改变一项：战斗距离、空间位置、主动权、武器状态、能力规则或环境条件。推荐功能链可从以下选择并重组：识别 → 抢先手 → 夺距离 → 格挡/闪避 → 变招 → 追击 → 反击 → 优势转换 → 环境或能力升级 → 终结。

“精彩、多回合、紧张刺激”默认要求双方都有主动选择，至少一次明显攻守互换，终结前已有充分受阻或反转。不要通过重复同一技能、增加无因爆炸或延长蓄力伪造回合。每回合都要能回答：剧情目标怎样变化、谁暂时占优、为什么进入下一回合。
