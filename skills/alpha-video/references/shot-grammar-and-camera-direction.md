# Shot Grammar：运镜导演系统（按需加载）

来源：《知识库-运镜与镜头语法.md》——Seedance2.0 运镜知识表（环境建立/投掷抛射/复合穿障/近战旋转/蓄力弹道/大场面/景别/基础运镜）。核心目标：把运镜能力从"堆叠推/拉/摇/环绕等术语"升级为"根据剧情目的、动作类型、空间结构和观众需要看清的重点，自动选择可执行运镜"的导演系统。**不把 Seedance2.0 句式、精确米/秒、精确秒数、0.2 倍慢放、黑场时长、高帧率保证、无卡顿保证、夸张特效词复制进核心层。**

与 `cinematography-and-storyboards.md`（摄影机人格/分镜）、`camera-action-environment-grammar.md`（三联规则/镜头锚点）配合：本文件负责"每镜怎么写、动作事件怎么选镜"。

## 1. 镜头语法单元（Shot Grammar，7 字段）

每一镜必须按以下结构描述（用于镜头执行表、分镜、路线图语义约束和最终视频执行稿）：

1. **shot_purpose 镜头目的**：建立空间/介绍主体/表现压迫/跟随起手/读清攻击轨迹/读清接触/读清闪避/展示受力方向/展示能力爆发/展示尺度/交代路线变化/强化人物表演/完成终局或转场。
2. **camera_start 摄像机起点**：景别；高低机位；相对主体的位置（前/后/侧/上/下/越肩）；起始焦点。
3. **camera_path 摄像机路径**：推进/拉远/横移/纵移/升高/下降/环绕/跟随/前引/尾随/俯冲/上摇/下摇；路径必须可达、可理解、能服务当前目的；**镜头运动应少而明确，不允许把所有运镜词堆叠在同一镜**。
4. **focal_subject 焦点与视觉主语**：当前观众必须看清的人物、武器、手部、眼神、飞行物、碰撞点、环境地标或终局对象；高速镜头保持焦点连续；允许焦点转移，但必须写清从什么转到什么、为什么转。
5. **trigger_event 触发镜头变化的动作事件**：起手/挥击/投掷/接触/闪避/格挡/回收/爆炸/坠落/破壁/召唤/终局；镜头的加速、减速、急停、拉远、切换或转向必须由事件触发。
6. **camera_end 镜头落点**：镜头结束时，人物、武器、飞行物、环境或终局处于什么可读状态；明确下一镜从哪个方向、姿态、武器状态、受力方向或环境状态继续。
7. **risk_and_budget 风险与复杂度**：活跃主体数量；独立动作链数量；镜头运动数量；特效系统数量；是否需拆镜或降负。

与现有六项框架兼容：镜头目的=shot_purpose，起始状态=camera_start，核心动作=trigger_event 对应动作，摄影机=camera_path，反馈=镜头落点与焦点，衔接=camera_end 的下一镜承接。

### 节奏强调扩展字段

需要自动强化关键动作时，保留七字段不变，并增加：`accent_enabled`、`accent_purpose`、`accent_trigger`、`accent_type`、`accent_focus`、`temporal_scope`、`motion_continuity`、`re_anchor`、`return_action`、`accent_risk`。`accent_focus` 直接复用本字段组中的 `focal_subject`；`temporal_scope` 默认是 `local_subject`，只有用户明确要求且平台适合时才允许 `full_scene`。强调点不是无因插镜，每个插镜只能有一个主要视觉重点，必须说明为何此时强化、观众要看什么、强调结束后如何回到主动作。

## 2. 动作事件 → 运镜选择系统

以下语法**不是固定模板**，而是根据动作事件选择的方法库：

### A. 建立空间、展示规模与引入主体
适用：开场、宏大场景、巨物/法相/建筑/灾难/战场、主角独独立于大环境。
可选方法：环境扫描后升高展示主体与周边空间；升高后水平扫描建立场景范围；从远景/高空向主体逐步收束；摇镜后升高将焦点转移到关键人物；斜向升镜表现山脉/河流/城墙/长街等长轴空间；升高过程中持续锁定主体表现人物在宏大环境中的存在感。
核心规则：先明确空间关系再追求宏大感；升/摇/拉远只服务"扩大空间信息、建立尺度或转移焦点"；不默认使用无人机式高空镜头；不使用精确米数或速度作为必须执行的模型参数。

### B. 投掷、抛射、飞行物与直线弹道
适用：飞刀/箭/枪/飞剑/能量弹/炸弹/巨石/法器/机械弹体；角色投掷、远程攻击、物体来袭、抛物线偷袭。
可选方法：从发射点/脱手瞬间读取手部与道具；跟随飞行物轨迹保持起点、方向和目标可读；从目标侧方预判读取闪避/擦身/命中；飞行物逼近时急拉回全景展示角色闪避与空间关系；回旋/回收武器时跟随回收路径再反向推向反击方向；多发射体项目先读一条主弹道再用短全景交代齐发规模。
核心规则：飞行物必须有发射点、轨迹、目标/擦身点、后果；禁止无因转弯、无因停顿、无来源出现、穿过实体无反馈；多物体齐发不让每个物体各自抢镜；慢放只允许极短服务关键闪避/命中/回收。

### C. 旋转、横扫、缠绕、回收与近战武器动作
适用：刀剑横扫/棍法/链锤/鞭/绳索/伞/回旋刃/旋转蓄力；近战范围攻击；束缚、缠绕、夺取、假动作与反击。
可选方法：围绕旋转中心短环绕后在发力起点或横扫末端急停；沿直线抽击/劈砍轨迹跟拍在命中点微距锁焦；跟随缠绕路径在收紧/锁住/挣脱/反制节点停止；大范围横扫后拉远展示受力范围/敌人反应/环境变化；道具回收时跟随回收轨迹再反向推进至第二次攻击。
核心规则：旋转镜头必须锁定旋转中心、武器轨迹或受力对象；武器轨迹、特效和摄影机不能各自独立旋转；动作末端必须有接触、受力、闪避、环境反馈或下一动作触发；禁止持续 360 度环绕而没有动作信息；不默认使用夸张血腥、皮肤撕裂、血痕喷溅等细节。

### D. 蓄力、瞄准、爆发与能力释放
适用：弓箭/枪械/法器/拳击蓄势/远程攻击/终极技能/机甲充能；角色从静止转入爆发。
可选方法：从手部/武器/关节/眼神/能量核心读清蓄力；小范围环绕或缓慢推进在蓄力顶点短促急停；从释放点快速推进再跟随能力/飞行物轨迹；静帧或克制镜头后用爆发式推进/拉远/受力方向跟拍形成反差；终局前可短促减速或定格但立刻回到可读后果。
核心规则：蓄力必须服务下一次攻击、变招或状态变化；不连续使用长蓄力镜头拖慢高速战斗；能量必须有来源、形成、释放、方向、接触和衰减；不能只写"能量爆炸"而没有战术和空间后果。

### E. 闪避、受击、躲避与反击
适用：主角高光、敌方攻击擦身、角色从劣势反转、近战或远程攻击的关键躲避。
可选方法：从攻击方向或目标侧方预判；攻击接近时保持目标身体、武器和威胁同框；闪避瞬间短促稳定或减速读清间隙与重心；沿躲避后的身体方向/武器方向/攻击空档转入反击；用短特写读取角色决断但不丢失攻击来源。
核心规则：闪避必须体现攻击路径、躲避方向、剩余间隙和下一步优势变化；禁止角色无因瞬移、攻击消失或镜头用模糊遮住闪避逻辑；不用"全局时间冻结"作为默认描述，只在风格和平台适合时作为导演意图。

### F. 群战、灾难、全域攻击与大尺度场面
适用：群战、天灾、万军冲锋、大范围能力、巨物攻击、场景级破坏。
可选方法：先用远景/高机位建立空间和阵营；再切入一条主攻防链或一个关键人物；用短全景重新交代规模与路线；大范围摇镜/拉远/高空视角只承担"规模展示"不替代可读动作；关键终局可用低机位、俯冲或受力方向展示压迫。
核心规则：群战每镜只突出一个主视觉和一条主因果；大场面不能让所有主体、特效、破坏和镜头运动同时独立运行；先减少背景独立事件和复杂环绕，再减少主攻防与优势转换；巨物、天灾和终局要有尺度参照、受力对象和环境后果。

## 3. 景别、机位与速度曲线（目的驱动选择表）

- **远景/全景**：建立空间、路线、人数、规模、环境威胁；巨物/建筑/群战/灾难/转场前后状态；不用于长时间读取手部接触或复杂武器变招。
- **中景**：读取身体动作、攻防关系、武器距离、角色位置；是大多数打斗动作的稳定阅读景别。
- **近景/特写/微距**：眼神、手势、武器状态、蓄力、接触点、受击反应、关键道具；不用来长时间承载复杂路线和多人关系；特写后应回到能重新建立空间的镜头。
- **俯拍/高机位**：路线、人数分布、空间尺度、落点、地形变化；不能让人物长期小到无法读取动作。
- **仰拍/低机位**：压迫、力量、巨物、飞跃、武器上举、能力爆发；不只为"霸气"而使用，必须服务角色与空间关系。

**速度曲线**：`建立/读取 → 跟进 → 关键事件 → 短促刹停或稳定 → 沿余势进入下一状态`。
规则：快不是持续快，镜头可在关键接触/闪避/命中/回收/终局处短暂停稳；慢不是拖，慢镜或静帧必须服务蓄力/表演/关键接触/终局；优先使用非静止时间延展，人物、武器、衣摆和环境继续运动，事件完成后立即回归主节奏；不使用精确速度、精确焦距和精确时长作为模型承诺；数字视作导演意图或测试范围，不是最终 Prompt 的硬参数。

### 3.1 叙事目的 → 信息变化 → 主运镜

动作事件不是唯一的镜头触发。情绪、认知、空间和受力状态发生变化时，先明确观众需要获得、失去或重新确认什么信息，再选择一个主要运镜：

| 叙事目的 | 主要信息变化 | 可选主运镜 | 触发与落点 |
|---|---|---|---|
| 情绪聚焦 / 判断形成 | 从身体关系收束到眼神、呼吸、手部或武器状态 | 受控缓推；危机瞬间可短促急推 | 由发现、犹豫、受击、觉醒或决断触发；落到会改变下一动作的表演结果，随后回到动作或空间锚点 |
| 空间揭示 / 尺度变化 | 从局部主体扩展到威胁区、阵营、路线或环境后果 | 拉远、升高、横移或短远景 | 由新威胁、破坏、目标暴露或路线变化触发；落到可识别地标和下一路径 |
| 主体跟随 / 路线读取 | 保持人物、装备、运动方向与环境关系连续 | 平行横移、前引、尾随、下降或弧形跟随 | 由冲刺、闪避、追逐、坠落或绕位触发；落到接触点、落点或新站位 |
| 受力 / 失衡 / 主观不稳 | 从稳定关系短暂转入冲击、眩晕或认知断裂 | 短促震动、轻微手持、受控倾斜或急拉 | 必须由爆炸、撞击、跌落、精神冲击等事件触发；迅速恢复水平线和主体锚点 |
| 尺度或心理关系改变 | 主体保持相对可读，背景关系发生压缩、扩张或抽离 | 受控推拉、变焦意图或拉远 | 用于压迫、顿悟、孤立或规模揭示；只描述视觉目的，不承诺精确焦段和轨道参数 |

选择规则固定为：`叙事目的 → 当前必看信息 → 一个主运镜 → 触发事件 → 可读落点 → 重新锚定`。如果一个镜头需要同时推、拉、横移、环绕、倾斜和震动，先删除不服务主要信息变化的运动；必要时拆镜。

### 3.1.1 六类视角职责映射

视角名不是风格标签。选镜顺序固定为：`观众信息任务 → 视角角色 → 触发事件 → 路径 → 焦点 → 落点/重新锚定`。每段只选择最能完成当前信息任务的一个主视角；需要换视角时必须由动作、认知、空间或尺度变化触发。

| 视角角色 | 观众信息任务 | 触发、路径与焦点 | 落点/重新锚定 |
|---|---|---|---|
| **鸟瞰** | 读取城市、战场、阵营、路线、包围或尺度拓扑 | 由新空间、路线暴露、群体调度或规模变化触发；缓推、下降或短拉远时锁定主轴、地标与主体相对位置 | 落到一条可识别路线、交锋节点或即将切入的主体；人物不能长期小到无法读动作 |
| **POV 主观视角** | 限制信息、制造临场感、误判、恐惧、受击或感知恢复 | 由角色看见、听见、回头、失衡、遮挡或重新聚焦触发；路径服从头部/身体运动，焦点是角色实际可感知的威胁、目标或工具 | 明确角色最终确认了什么，并在必要时切回人物、武器、攻击来源或空间锚点；不能用黑暗和晃动遮掉关键接触结果 |
| **横移** | 顺序揭示多人、维持动作轴、做角色焦点接力或读取侧向位移 | 由视线、发言、角色接管任务、冲刺或贴身缠斗触发；沿可达水平路径移动，一次只把一个角色、动作或道具交给清晰焦点 | 落到接管下一行动的人、关键道具或新站位；焦点切换必须继承身份、方向和角色数量 |
| **FPV** | 让观众沿危险路线高速穿越，读取障碍险距、空间压迫与目标逼近 | 由障碍、急转、坠落、追逐或路线选择触发；沿连续可达路径前进，焦点保持在航线、主体或下一个避障节点 | 在地标、出口、追逐目标或危险结果处重锚；不得无因穿墙，也不承诺一镜到底、帧率或绝对顺滑 |
| **ACT 第三人称** | 同时读清主角动量、敌人威胁、武器距离和接触结果 | 根据当前主问题只选“共享主角动量、确认敌人受力、保持连续过程”之一；跟拍、受控半环绕或短推由攻防事件触发 | 接触后恢复主角、敌人、武器和优势关系；ACT 不是低机位、甩镜、慢动作和环绕的固定套餐 |
| **尺度穿越** | 从宏观世界快速收束到具体地点、载具、人物或战斗目标，建立尺度反差 | 由目标被识别或叙事焦点收束触发；俯冲、穿云、下降、贴地追随等路径必须连续，焦点逐级从大地标交接到局部主体 | 最终同时保留目标主体、局部方向和至少一个环境参照；不得靠无因瞬移完成宏观到微观切换 |

这些视角可以跨镜接力，但不能在同一短镜头并行承担六套摄影系统。原文中的 8K、120fps、精确光圈、固定秒点、一镜到底和“绝对流畅”只属于设计意图或后期目标；未确认平台能力时不得写成生成保证。听觉、气味和触感只能转译为可见反应、环境状态或声音设计，不能当作画面已经直接呈现的事实。

### 3.2 动机转场门禁

转场不是单独的视觉花活，必须继承动作、空间或信息因果：

- **动作匹配**：上一镜的抬手、转身、挥击、坠落或奔跑方向承接下一镜的同向动作；
- **形状 / 颜色 / 声音匹配**：只在相似构图、色块或声音能帮助观众识别关系时使用，不能因相似而改写角色或资产；
- **遮挡 / 擦镜**：人物、武器、门框、烟雾、布幔或飞散物自然遮挡画面后进入下一空间；遮挡前后继承主体身份、运动方向和关键状态；
- **穿越材质或边界**：穿过门框、玻璃、水面、烟雾或屏幕必须有可达路径或明确的现实—回忆—异空间叙事逻辑；不得无因穿过实体人物、墙体或武器；
- **甩镜 / 故障跳转**：只用于追逐、突发视线转移、系统异常或主观认知断裂；模糊、噪点和色偏不能遮住必须看清的动作结果。

转场后至少恢复一个锚点：人物身份、武器状态、运动方向、环境地标、受力结果或战场优势。无法说明“为什么现在转、转过去继承什么”的转场删除。

### 动作触发的摄影机重新捕捉

高速跟进允许产生短促“捕捉差”：主体先变向或攻击，摄影机因惯性短暂滞后/过冲，随后沿动作或受力方向重新捕捉。Shot Grammar 必须写出触发事件、追赶路径、持续焦点和落点；落点至少恢复人物、武器、接触、受力、环境结果或优势中的一个。它不能与多主体独立变向、复杂变形和多套 VFX 同镜叠加，也不能把镜头追丢主体包装成速度感。

### 3.3 特殊运镜与时间强调边界

- **子弹时间**不是固定的 360° 环绕，也不是全场完全冻结。默认只延展关键接触、闪避、优势转换或终局中的局部主体；人物、武器、衣料和环境保持非静止运动，随后立即恢复实时高速并重新锚定。
- **旋转 / 环绕**必须锁定单一接触中心、人物关系或武器轨迹；不把人物、武器、特效和摄影机设为多个独立旋转系统。
- **一镜到底**由空间连续、动作可达和信息负载决定，不以固定超过 30 秒作为定义；主体、路线或特效过载时拆镜。
- **希区柯克式推拉 / 变焦意图**只表达主体与背景关系改变，不把焦段、轨道距离或精确速度写成平台承诺。
- 源案例或词表中的米数、角度、速度和秒数只能作为导演意图或测试变量；最终 B 稿按平台承载压缩。

## 4. 红线

- 每个镜头必须回答：为什么从这里看、现在要看什么、为什么此时移动、落在哪、下一镜怎么接；
- 无因穿墙/穿地/穿角色、无因越轴、无因机位跳变、无意义持续环绕/甩镜/震动/旋转均禁止；
- 关键命中、闪避、接触和终局不得被镜头运动或特效遮住；
- 一个短镜头内不得同时承载多条互不相关动作链、多个主体、多个特效和多个摄影机运动；
- 默认电影级、非猎奇伤害表现；不默认皮肤撕裂、血痕喷溅等细节；
- 不把精确速度/焦距/秒数/慢放比例/高帧率/无卡顿写成模型保证。
