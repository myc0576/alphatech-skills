# 打斗视频负面约束词库与选用规则

本词库由样本文档中的稳定性约束、负面词和失败诊断归纳而来。它是按风险取用的检查表，不是每次整段复制的固定尾巴。

## 1. 先锁定，再禁止

先用正向句声明不可变化的资产与叙事事实：

- 同一人物的脸、年龄感、发型、体型、服装、标志物与阵营。
- 武器数量、结构、左右手、握持方式、能力属性和状态变化逻辑。
- 场景主轴、地标、高低位、路线、交锋点、破坏累积和伤痕连续性。
- 人数关系、战斗目标、胜负状态、伤害尺度和结尾状态。

再用负面约束拦截最高风险。正向锁定负责告诉模型正确答案，负面词负责阻止它走向常见错误；两者不要逐句机械重复。

## 2. 选用算法

1. 判断平台是否有独立负面提示词栏；没有时，把约束放在执行 Prompt 末尾。
2. 默认保留“画面污染”组；路线图、分镜板或带标注参考图参与时使用完整版本。
3. 从身份/武器、动作接触、空间连续、摄影、特效环境中各选最相关的 1–3 条。
4. 再按项目的人数结构、风格、能力、伤害尺度和结局添加专项条目。
5. 优先写可观察错误，例如“刀始终只有两把，禁止合成单刀”，少写空泛词，例如“不要不好看”。
6. 若一句负面词会误伤正向设计，删除或改成带条件的边界。总长度以模型仍能记住主要动作因果为限。

## 3. 通用基础词库

### 3.1 画面污染与参考图泄漏

路线图或设计板参与时优先使用：

> 禁止字幕、标题、文字、数字、Logo、水印、品牌名、人物姓名标签、技能名、镜头编号、边框、路线箭头、红蓝轨迹线、节点标记、图例、中文说明、缩略图、底部说明栏、面板和任何 UI 出现在最终成片；只继承路线、交锋节点与镜头节奏，不生成路线图本身或重复人物示意。

没有标注参考图时可压缩为：

> 禁止字幕、标题、Logo、水印、说明文字、边框和 UI。

### 3.2 角色、阵营与数量

- 禁止换脸、五官变化、年龄/性别漂移、发色或发型变化、体型突变、服装与标志物随机改变。
- 禁止角色丢失、同一角色出现复制体、主角数量增加、敌我阵营交换或人物职责互换。
- 群体敌人禁止完全同脸、同姿势、同速度的机械复制；禁止随机刷新、凭空消失、倒下后无因复活。
- 禁止临时引入未定义人物、召唤物、坐骑、翅膀、护盾或装备。

### 3.3 武器、能力与状态连续

- 禁止武器数量漂移、左右手交换、手掌脱离握柄、尺寸和结构随机变化、武器凭空出现或消失。
- 禁止不同角色交换武器、元素、技能与战斗职责；禁止加入未定义的火、冰、雷、毒、圣光、魔法阵或枪械。
- 有变形武器时，禁止跳变或两种形态无因同时存在；必须看清旧形态收束、结构转化与新形态完成。
- 有计数能力时，禁止无限增殖或无因耗尽；发射、破碎、回收与重新凝聚必须连续。
- 禁止特效轨迹先于身体转向、脱离武器/肢体路径、延迟跟随、自己拐弯或没有明确起点、介质与终点。

### 3.4 动作、接触与物理

- 禁止卡顿掉帧感、动作断层、无故停顿、姿势瞬间跳变、肢体瞬移和连续动作缺少过渡。
- 禁止攻击打空却出现命中爆点、拳脚或武器未接触就击飞、技能未碰撞就提前爆炸、攻击穿过目标而无反馈。
- 禁止穿模、关节反折、多手多脚、手指畸形、手掌融合、错误重力、无故悬浮、脚底打滑和无重心漂移。
- 禁止摆拍、站桩、软绵无力、双方等待轮流攻击、敌人排队送死；写实慢节奏项目只排除“无动因停顿”，不要强制高速。
- 禁止受力方向与攻击方向相反、所有敌人同帧同姿势整齐倒飞、命中后完全没有重心变化或材质反馈。
- 禁止同一镜头同时塞入多组互不相关、无法读取接触点和受力方向的复杂攻防；允许一条方向清楚、前后相连、由上一动作直接触发的 2–4 步微动作因果链。

### 3.5 空间、路线与场景连续

- 禁止人物瞬移到不符合路线的位置、越过实体障碍、交锋双方无法到达同一碰撞点、路线前后断裂。
- 禁止无理由越轴、左右关系或运动方向反复翻转、镜像切换造成阵营错位。
- 禁止地标跳变、建筑闪烁、道路/地面结构突变、高低位消失、背景原地旋转和破坏结果下一镜复原。
- 禁止场景机制无因出现或消失，例如冰道突然中断、绳索无受力摆动、裂纹漂浮、碎片静止。

### 3.6 摄影与可读性

- 禁止摄影机持续乱晃、机械抖动、无意义旋转、突然翻转、频繁换机位或穿过人物、武器、墙体和地面。
- 禁止主体长期出画、丢失或被遮挡；禁止持续脱焦、全程运动模糊、曝光跳变和色温漂移。
- 禁止全程平速，也禁止全程高速乱甩；接触点需要稳定、减速或短暂停顿供观众读取。
- 禁止长时间慢动作、全局时间冻结和静止摆拍。全局固定块中的“子弹时间”必须在关键接触、闪避、命中、反转或终局处短促出现，并立即恢复实时高速；`auto_adaptive` 只决定是否增加其他节奏强调。用户明确“不要慢动作”时，禁止长时间或额外时间延展，但仍保留固定块文字，并把子弹时间压缩为接触瞬间的短促速度变化；动作、表情或受击反馈特写不受影响。
- 禁止无因动作特写、重复脸部特写、与攻击事件无关的反应镜头、特写后丢失人物/武器/空间关系、强调后没有后续结果。

### 3.7 特效、环境与材质反馈

- 禁止廉价贴图感、塑料材质、扁平光影、特效漂移、静止装饰光和所有效果从开场到结尾始终满强度。
- 禁止全屏光、烟、雾、血雾、碎片或过曝长期遮住脸、身体动作、武器结构、命中点和空间轮廓。
- 禁止特效没有常态—运动—攻击—命中—衰减生命周期；禁止脱离角色动作独立表演。
- 禁止场景无反馈、破坏与攻击不匹配、碎片不受重力、积水没有反射/波纹、烟尘不受冲击、材质破坏类型错误。
- 短促运动模糊、爆闪和过曝可以服务速度、切镜或高潮，但关键动作落点必须清晰。

### 3.8 伤害尺度与结尾

- 先按用户目标选定无伤切磋、电影级非猎奇、明显但克制的伤害或其他尺度。
- 无伤/低伤项目：禁止大量鲜血、开放性伤口、肢解、器官内脏与猎奇特写。
- 允许电影级伤害的项目：禁止持续血浆和血雾长期遮挡主体，同时不要用“完全无伤、完全无受击反馈”抵消正向设计。
- 结尾约束必须写成项目事实：胜负未分则禁止一方倒地认输；明确胜负则禁止双方无因恢复；撤离/护送则禁止变成清场摆拍；Boss 局部破坏则禁止全身爆炸或伤处漂移。

## 4. 人数结构专项

### 一对一或势均力敌切磋

- 禁止任何一方无因反派化或长期单方面压制。
- 禁止两人的能力、服装、武器与攻击颜色互换。
- 多次碰撞必须各自可读，禁止合并成一团无来源的能量爆炸。

### 一对多

- 禁止敌人围成整齐队列依次送死、所有人同步扑击或同步倒飞。
- 禁止背景敌人随机出现消失；主角路线与局部敌群的交锋顺序必须连续。
- 禁止主角无接触清场；范围攻击仍需传播路径、受力差异和环境反馈。

### 团队协同与多对多

- 禁止队员各打各的、职责互换、支援角色无因进入近战或主攻角色突然退化为站桩法师。
- 禁止多种属性混成一团无法分辨来源的彩光；保留控场—切入—接力—终结的先后关系。
- 禁止所有人同时成为视觉主角；每镜只突出一个动作因果，其余角色维持支援关系。

### Boss 战

- 禁止 Boss 尺度、结构和弱点位置漂移；禁止主角无因正面对轰取得胜利。
- 禁止弱点未暴露就提前受损、机关没有因果就启动、指定局部伤害扩散成全身解体。
- 禁止 Boss 倒地后尺寸缩小、装甲复原或下一镜重新无伤站起。

## 5. 风格与能力专项

只在对应项目使用，不要把某一风格的排除项写成全局规则。

### 写实格斗/武侠

- 禁止动作漂浮、武打摆拍、夸张无重力飞行、无接触倒飞和兵器距离失真。
- 雨雪环境禁止像固定滤镜；地面湿度、衣料、足迹、溅水和材质破坏必须响应动作。
- 写实项目可排除卡通、插画、塑料皮肤和廉价游戏 CG；动漫项目不得使用这条。

### 冰系

- 禁止普通武器只套蓝光、柔和仙气、雪花滤镜和梦幻雾气替代冰晶结构。
- 禁止冰箭瞬移、冰层没有厚度和生长逻辑、冻结没有接触路径、碎冰与受力无关。
- 冰莲、冰墙、冰道等标志技能必须保持其指定形态，禁止退化为普通冰圈或地面闪光。

### 火系

- 禁止塑料火焰、贴纸火焰、无热浪、无烟、无火星、无反射、无积水蒸汽和无环境照明反馈。
- 禁止火焰属性随机变色或混入未定义元素；禁止火焰完全遮住刀体、脸和命中点。
- 禁止刀弧提前生成、脱离刀体、自行转弯或运动方向与挥斩相反。

### 雷电/能量

- 禁止简单贴身蓝线、完全相同的重复闪电、僵硬对称雷环、固定电弧、柔和仙气和梦幻光雾。
- 禁止电流没有起点、传导介质、接触对象、痉挛/焦黑/照明等结果；禁止身体未动而雷轨先转弯。
- 禁止所有雷球或能量体像装饰灯静止漂浮、无因无限增殖或同时遮住人物。

### 机甲/赛博

- 禁止塑料感机甲、刚体滑行、关节没有伺服/液压迟滞、钢缆无张力和金属撞击无形变。
- 禁止机械结构尺寸漂移、装甲穿插、武器挂点变化和损伤区域下一镜复原。
- 霓虹、全息屏、电火花与雨水必须产生材质反射，不能只做悬浮装饰粒子。

### 中式志怪/恐怖

- 禁止符箓、法阵和黑雾像廉价贴图；必须响应风、角色动作、地面结构与光线。
- 禁止场景过亮或恐怖主体长期完全暴露；同时禁止黑雾遮住全部动作和空间。
- 禁止幽灵/黑影穿模造成因果失真；若穿透是设定能力，必须提前建立规则并给出状态反馈。

## 6. 输出前冲突检查

逐项确认：

- 有没有禁止用户明确要求的风格，例如动漫项目却写“禁止动漫风”。
- 有没有既要求大规模破坏又写“禁止场景破坏”，或既要求无伤切磋又要求血雾/断肢。
- 有没有既要求慢镜审美又写“禁止慢动作”，或既要求手持纪实又把所有镜头抖动都禁止。
- 有没有把特定案例结局写成通用规则，例如所有视频都必须留钩子、清场或双方站立。
- 有没有要求大量敌人完全一致，同时又禁止复制感；群体可以同种族，但应有姿态、装备磨损和脸型差异。
- 有没有用过多负面词挤掉核心动作。若有，优先保留身份/武器、关键接触、空间连续与画面污染四类。
- 有没有以“稳定性”为理由禁止格挡后的变招、攻击后的追击或即时反击，导致连续打斗退化成几个孤立动作。
